# LUXE
نسخه پایه قابل اجرای وب از شبکه اجتماعی LUXE با React + Vite + Supabase.

## اجرا
1. Node.js نصب باشد.
2. `npm install`
3. `.env.example` را به `.env` تغییر نام دهید و URL و Anon Key پروژه Supabase را وارد کنید.
4. محتوای `supabase/schema.sql` را در SQL Editor سوپابیس اجرا کنید.
5. `npm run dev`

## ساخت نسخه production
`npm run build`

خروجی در پوشه `dist` ساخته می‌شود.
